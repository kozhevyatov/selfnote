# Проверка заметок «Пароли»

Автоматические проверки агент не запускал по просьбе владельца.

```sh
cd /Users/nskarl/www/selfnote/app
npm run typecheck
npm run lint
npm test
npm run test:integration
npm run build
```

## Проверить вручную

1. В меню стрелки у «Новая заметка» выбрать «Пароли». Задать мастер-пароль (минимум 12 символов), проверить несовпадающее подтверждение. При повторной настройке с другого устройства существующий ключ не должен заменяться.
2. Создать два блока доступов, задать название, поменять порядок, дублировать и удалить блок. Проверить показ одного пароля, копирование и генератор с подтверждением замены. Не использовать реальные пароли до проверки.
3. Убедиться, что раздел «Пароли» находится под «Задачами», содержит только секреты, а создание из него предлагает секрет. Перенос в книжку, закрепление и корзина должны сохранять тип.
4. Заблокировать вручную, перейти в другую вкладку, подождать 5 минут бездействия. Содержимое и названия должны скрыться. Неверный мастер-пароль не открывает хранилище; верный открывает загруженные записи. Проверить уход из вкладки сразу после ввода последнего символа.
5. Сначала синхронизировать, затем отключить сеть. Создать и изменить секрет, перезагрузить страницу, разблокировать, включить сеть и открыть на другом устройстве.
6. Изменить одну заметку независимо офлайн на двух устройствах. После синхронизации должны сохраниться обе версии, одна — копией «(конфликт)».
7. Сохранить версию, изменить пароль, восстановить версию. Проверить возврат исходного пароля и возможность вернуть состояние до восстановления.
8. Обычный экспорт должен пропускать секреты с предупреждением. Проверить полный серверный бэкап и восстановление на тестовом экземпляре: секреты открываются старым мастер-паролем.
9. Проверить запрет публичной ссылки, смены/снятия пароля отдельной записи и совместного доступа. Поиск не должен находить значение пароля; после блокировки — скрытое название.
10. Проверить перо в шапке и favicon, PWA-иконки после обновления установки; отступы кнопки очистки корзины при наведении.

## Ограничения первой версии

- Восстановления и смены мастер-пароля пока нет. Утрата пароля означает утрату доступа к секретам.
- TOTP, вложения и отдельный перенос хранилища между аккаунтами не реализованы.
- История секретов хранит последние 50 разных версий внутри зашифрованного документа, отдельно от истории обычных заметок.
- Буфер обмена браузер может запретить читать/очищать. Очистка не выполняется, если окно неактивно или в буфере уже другое значение.
- Книжки, метки, наличие и даты секретов остаются открытыми метаданными.
